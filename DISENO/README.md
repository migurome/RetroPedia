# DISENO — diseño de niveles y de mundo

Teoría y práctica de diseño de niveles para plataformas 2D y metroidvanias. Leer en este orden:

1. [Principios de diseño de niveles](principios-diseno-niveles.md) — Dan Taylor, kishōtenketsu, enseñar sin texto, ritmo, riesgo/recompensa.
2. [Guiar al jugador](guiar-al-jugador.md) — affordances, líneas guía, migas de pan, landmarks, Lynch, técnicas de Super Metroid y Hollow Knight, reglas de colocación.
3. [Diseño de mundo metroidvania](mundo-metroidvania.md) — llaves/cerraduras, grafo de dependencias, puertas de un sentido, atajos, backtracking, tipos de sala.
4. [Métricas y cámara](metricas-y-camara.md) — bandas seguro/exigente/imposible, espacio libre, técnicas de cámara.
5. [Aplicación a Retrovania](aplicacion-retrovania.md) — métricas reales del héroe en tiles, procedimiento para crear una sala, checklist y patrones ASCII.

Para crear o revisar una sala de Retrovania basta con la entrada 5; las demás explican el porqué.
